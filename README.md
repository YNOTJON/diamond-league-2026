# Diamond League 26 — Mobile Baseball Prototype

## Run it
1. Unzip the folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension (or use any local static web server).
4. Right-click `index.html` → **Open with Live Server**.
5. Open the local URL on your phone or desktop.

## Controls
- Touch: drag the green target reticle on the field, then tap Normal Hit, Power, Bunt, or Throw Pitch.
- Keyboard: `X` normal hit, `Q` power, `W` bunt, `Space` pitch, arrow keys move the target.
- PS4 controller: connect by USB or Bluetooth before opening the page. Standard Gamepad API mappings are used; mapping can vary by browser/OS. On typical standard mapping: Cross = normal hit, Square = power, Triangle = bunt, Circle = pitch, L1/R1 cycle pitch types, left stick aims.

## What's included
- Mobile-responsive original baseball UI and 2D canvas field.
- 30 MLB clubs and their ballpark names for team/park selection.
- Optional 2026 active/40-man roster fetch from the public MLB Stats API.
- Batting practice and pitching practice.
- Normal, power, and bunt swings; selectable pitch types; count and simple outcomes.
- Browser Gamepad API input and touch/keyboard controls.

## Important prototype limits
This is a playable starter prototype, not a full simulation. It does not include full 3D animation, online multiplayer, franchise/season modes, licensed MLB player likenesses, or verified pitch repertoires for every pitcher. Pitch speeds/outcomes are simplified gameplay estimates. Roster fetch requires internet access and may depend on the API/browser availability. No official MLB or Sony affiliation.
